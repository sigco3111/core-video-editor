# 코어 비디오 에디터 (Core Video Editor)

**Gemini AI 기반의 지능형 웹 비디오 편집기**

이 프로젝트는 최신 웹 기술과 Google의 강력한 Gemini AI를 결합하여 사용자에게 직관적이면서도 강력한 비디오 편집 경험을 제공하는 클라이언트 사이드 비디오 편집기입니다. 사용자는 로컬 비디오 파일을 업로드하고, 타임라인 기반으로 편집하며, AI 기반의 고급 기능을 활용하여 창의적인 비디오 콘텐츠를 손쉽게 제작할 수 있습니다. 모든 처리 과정은 브라우저 내에서 이루어지며, 작업 내용은 자동으로 로컬에 저장됩니다.

실행주소1 : https://sigco3111.github.io/core-video-editor/

실행주소2 : https://dev-canvas-pi.vercel.app/


## ✨ 주요 기능

- **타임라인 기반 편집**: 클립 추가, 순서 변경, 길이 조절(트리밍) 등 직관적인 타임라인 인터페이스를 제공합니다.
- **유연한 타임라인 길이**: 클립을 타임라인 끝으로 드래그하면 동영상 길이에 맞춰 타임라인이 자동으로 확장됩니다. 또한, 플레이어에서 원하는 최소 프로젝트 길이를 직접 설정할 수도 있습니다.
- **실시간 미리보기**: 편집 내용을 실시간으로 확인하며 작업할 수 있습니다.
- **비파괴 편집**: 원본 미디어 파일은 안전하게 유지되며, 편집 내용은 별도로 관리됩니다.
- **로컬 프로젝트 저장**: 모든 작업 내용은 IndexedDB를 통해 브라우저에 자동으로 저장되어, 페이지를 새로고침하거나 닫아도 작업 내용을 잃지 않습니다.
- **비디오 내보내기**: 편집이 완료된 비디오를 단일 `mp4` 파일로 내보낼 수 있습니다.
- **반응형 UI**: Tailwind CSS를 사용하여 다양한 화면 크기에 대응합니다.

### 🤖 Gemini AI 기반 지능형 기능

- **AI 자동 자막 생성**: 비디오 클립의 오디오를 분석하여 자동으로 타임스탬프가 포함된 자막을 생성합니다.
- **AI 스마트 컷**: 비디오의 시각적 내용을 분석하여 장면이 전환되는 지점을 자동으로 감지하고 클립을 분할합니다.
- **AI 효과 생성**: "흑백으로 만들어줘" 또는 "웃는 강아지 사진 추가"와 같은 간단한 프롬프트를 입력하면 AI가 적절한 필터 효과나 이미지 오버레이를 생성하여 적용합니다.
- **AI 생성 전환 효과 (Generative Transition)**: 두 클립 사이에 "화면이 유리처럼 깨지는 효과"와 같은 창의적인 전환 효과를 프롬프트만으로 생성하여 적용합니다.

## 🛠️ 기술 스택

- **프론트엔드**: React, TypeScript, Tailwind CSS
- **AI**: Google Gemini API (`@google/genai`)
- **비디오 처리**: WebCodecs API, `mp4-muxer`
- **상태 관리**: React Hooks (useState, useMemo, useCallback)
- **로컬 데이터베이스**: IndexedDB (프로젝트 상태 지속성)
- **빌드 시스템**: 브라우저의 ES Modules 및 `importmap`을 직접 활용하여 별도의 빌드 과정 없이 실행됩니다.

## 🚀 시작하기

이 애플리케이션은 웹 기반이므로 별도의 설치가 필요 없습니다. 웹 브라우저에서 `index.html` 파일을 열기만 하면 됩니다.

### 필수 요구사항

- 최신 버전의 Chrome, Edge 등 WebCodecs API를 지원하는 모던 웹 브라우저.
- **Google Gemini API 키**: AI 기능을 사용하기 위해 필수적입니다. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 무료로 발급받을 수 있습니다.

### 사용 방법

1.  **API 키 설정**:
    -   애플리케이션 우측 상단의 `Gemini API 키 입력` 필드에 발급받은 API 키를 붙여넣습니다.
    -   `저장` 버튼을 클릭합니다. API 키가 유효하면 상태 표시등이 녹색으로 바뀝니다.

2.  **미디어 추가**:
    -   좌측의 '미디어 라이브러리' 패널을 클릭하거나 비디오 파일을 드래그 앤 드롭하여 프로젝트에 추가합니다.
    -   비디오가 추가되면 썸네일이 자동으로 생성됩니다.

3.  **타임라인 편집**:
    -   미디어 라이브러리에서 원하는 비디오를 하단의 타임라인으로 드래그 앤 드롭하여 클립을 추가합니다.
    -   타임라인의 클립을 드래그하여 위치를 옮기거나, 클립의 양쪽 끝을 드래그하여 길이를 조절할 수 있습니다. 클립을 타임라인 끝으로 드래그하면 타임라인이 자동으로 늘어납니다.
    - **프로젝트 길이 설정**: 플레이어의 시간 표시(예: `0.00s / 30.00s`)에서 전체 길이를 클릭하여 원하는 최소 프로젝트 길이를 설정할 수 있습니다.

4.  **기본 도구 사용**:
    -   타임라인에서 클립을 선택하고 재생 헤드(빨간색 막대)를 원하는 위치로 옮긴 후, 상단 툴바의 `분할` 버튼을 눌러 클립을 자를 수 있습니다.
    -   `텍스트 추가` 버튼으로 현재 재생 헤드 위치에 텍스트 오버레이를 추가하고, 우측 속성 패널에서 내용을 수정할 수 있습니다.

5.  **AI 기능 활용**:
    -   타임라인에서 클립을 선택하면 우측 '속성' 패널이 활성화됩니다.
    -   **자동 자막/스마트 컷**: `AI 자동 자막 생성` 또는 `AI 스마트 컷` 버튼을 클릭하여 해당 기능을 실행합니다.
    -   **수동 효과**: "빈티지 필름처럼 보이게" 같은 프롬프트를 입력하고 `효과 적용` 버튼을 누릅니다.
    -   **AI 전환 효과**: 두 클립이 인접해 있을 때 나타나는 `AI 생성 전환 효과` 입력란에 원하는 효과를 묘사하고 `전환 효과 적용` 버튼을 누릅니다.

6.  **내보내기**:
    -   편집이 완료되면 우측 상단의 `비디오 내보내기` 버튼을 클릭합니다.
    -   렌더링이 진행된 후, 결과물이 `edited_video.mp4` 파일로 다운로드됩니다.
